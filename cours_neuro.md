#Quelle est la différence entre Git et GitHub?

## Git est un logiciel que tu installes sur ton ordinateur.
Il permet de :
- Suivre les modifications de ton code.
- Enregistrer différentes versions de ton projet.
- Revenir à une ancienne version si tu fais une erreur.

## GitHub est un site web qui permet d'héberger tes projets Git sur Internet.

Il permet de :
- Sauvegarder tes projets en ligne.
- Partager ton code avec d'autres développeurs.
- Travailler en équipe.
- Découvrir et contribuer à d'autres projets.
